Calibration strip

A lane you can tape onto the floor in 20 minutes. Run the same short programs on it in FLL Practice (pick Calibration strip in the table menu) and on the real robot, then compare. The differences tell you what to adjust before trusting the simulator on the full table.

Top view, to scale. The robot (red dashed outline) starts with the middle of its wheels on the start line, pointing at the wall. Everything is measured from the start line along the lane.

What you need

  • White paper about 170 × 60 cm: a roll of butcher paper, or 3 poster boards taped together. Brown cardboard or a wooden floor confuses the color sensor.
  • Black electrical tape (19 mm), for the start line and the stop line.
  • Blue painter's tape, for the two lane edges.
  • Red, green and blue construction paper (or colored tape), cut into 5 × 26 cm strips.
  • A cardboard box at least 50 cm wide and 15 cm tall, for the wall. A piece of cardboard propped up with books works too.
  • A tape measure, a ruler, a marker and a pencil.

Build it

  1. Tape the white paper flat on a hard floor or a long table. Tape every edge so the wheels don't lift it.
  2. About 30 cm from one end, put down the start line: black tape straight across, 40 cm long. Mark its middle.
  3. With a pencil, draw the lane's middle from that mark to the far end, at right angles to the start line. Use the corner of a poster board or a big book to get the right angle.
  4. Put the two lane edges in blue tape, from 20 to 135 cm. The inside edge of each tape is 14 cm from the middle, so the lane is 28 cm wide.
  5. Outside each edge, draw a short tick every 10 cm from 10 to 130 and write the number next to it.
  6. At 40 cm, put the stop line across the lane in black tape, 28 cm long.
  7. Glue or tape the colors across the lane, centered at red 60 cm, green 75 cm, blue 90 cm.
  8. Stand the wall across the lane with its face exactly 140 cm from the start line.
  9. Optional: around the start, draw thin pencil lines every 45° (a star), 25 cm long. It shows how far a turn went.

In FLL Practice, Reset position puts the robot on the start line in the same place. The box at the top right of the 3D view gives the numbers you would measure with a tape measure.

The tests

Use the same robot build in the simulator as on the table. Write each program once in FLL Practice, run it there, then export it (Save .llsp3) and run the same file on the real robot. Do every real test 3 times: the real robot changes a little each run.

1Distance and drift
move forward 100 cm (speed 50) write timer
Measure how far past the start line the middle of the wheels stopped (read the ticks beside the wheels), and how far the robot is off the lane's middle. The timer shows how long it took. Try speed 100 too.
2Spin by wheel turns
move with steering 100 for N rotations
In the simulator, find the N that turns the robot exactly once (the box says "straight down the lane"). Run the same N on the real robot and see where it points. Real tires slip in a spin, so it usually turns less.
3Turn with the gyro
set yaw angle to 0 start moving with steering 100 (speed 30) wait until yaw > 89 stop moving move forward 100 cm
Repeat the turn 4 times before the drive, so the robot comes back to straight. A 1° error moves it 1.7 cm sideways after 100 cm, so measure how far off the lane's middle it ends up. Try speed 60 too: faster turns overshoot more.
4Stop on the line
start moving (speed 30) wait until color sensor is black stop moving
Measure where the wheels stopped. The line is at 40 cm, but the sensor is ahead of the wheels, so the wheels stop before it. Then try speed 70: how much further does it coast?
5Colors Same as test 4 with red, then green, then blue. Does the real sensor see each color? If not, find out what it does see (write the color sensor's color on the light matrix).
6Stop before the wall
start moving (speed 30) wait until distance < 20 cm stop moving
Measure where the wheels stopped. Try 10 cm and speed 70 as well.

What to change when they differ

  • Distance: if the real robot went 97 cm instead of 100, change the set 1 motor rotation to … cm moved block in its program: new value = old value × 97 ÷ 100. Then test 1 again.
  • Drift: a robot that curls one way needs its tires checked (same tires, pushed on all the way) before anything else.
  • Turns: use the gyro (test 3) for turns that matter. For wheel-turn spins, use the real robot's N, not the simulator's.
  • Line, colors, wall: if the real robot coasts further, slow down before the line or the wall. If a color doesn't read, pick another color or use reflected light.
