Calibration strip

Two printed sheets, a tape measure and a cardboard box on any table about 1.4 m long. Run the same short programs on it in FLL Practice (pick Calibration strip in the table menu) and on the real robot, then compare. The differences tell you what to adjust before trusting the simulator.

The 2 sheets to print (PDF) Print this page (with the results sheet)

Top view, to scale. The robot (red dashed outline) starts with the middle of its wheels on sheet 1's black line and drives toward the box. Every distance is read off the tape measure.

What you need

  • The 2 sheets from the PDF, printed in color on US letter paper.
  • A tape measure in cm, at least 1.2 m (a metal one stays straight best).
  • Masking tape, a ruler, and a cardboard box at least 25 cm wide and 10 cm tall for the wall.
  • A table at least 1.4 m long. No cutting or joining.

Set it up (10 minutes)

  1. Print the PDF at 100% / Actual size, not "Fit to page". Check the 10 cm bar on each sheet with a ruler.
  2. Tape sheet 1 near one end of the table, the robot driving "up the page" along the table.
  3. Lay the tape measure along sheet 1's right edge, with its 0 at the start line (the "tape measure 0 here" mark). Pull it out to about 120 cm, straight along the table, and tape it down at the start, the middle and the end.
  4. Put sheet 2 with its near edge at 36 cm and its right edge touching the tape measure. Tape it down. Its black line is now at 42 cm.
  5. Stand the box across the lane with its face at 110 cm, square to the tape measure. Tape it down.

Because both sheets touch the tape measure, they are in line without measuring sideways. In FLL Practice, Reset position puts the robot on the start line, and the box at the top right of the 3D view gives the same numbers you would read off the tape measure.

The tests

Use the same robot build in the simulator as on the table. Write each program once in FLL Practice, run it there, then export it (Save .llsp3) and run the same file on the real robot. Do every real test 3 times: the real robot changes a little from run to run. Start every run with the wheels' middle on the start line and the robot's middle on the dashed line.

1Distance and drift
move forward 80 cm (speed 50) write timer
Read where the middle of the wheels stopped on the tape measure. For drift, measure the gap between the robot's right side and the tape measure at the start and at the end: the difference is how far it drifted. The timer shows how long it took. Try speed 100 too.
2Stop on the line
start moving (speed 30) wait until color sensor is black stop moving
Read where the wheels stopped on the tape measure, and where the robot's middle is on sheet 2's scale (read both sides of the robot and take the halfway point). Then try speed 70: how much further does it coast?
3Colors Same as test 2 with red, then green, then blue. Does the real sensor see each color? If not, find out what it does see (write the color sensor's color on the light matrix).
4Spin by wheel turns
move with steering 100 for N rotations then test 2's three blocks
In the simulator, find the N that turns the robot exactly once (the box says "straight down the lane"). Run the same N on the real robot. Compare where the robot's middle crosses sheet 2's scale with test 2: every 1° the spin is off moves it about 0.7 cm sideways. Real tires slip in a spin, so it usually turns less.
5Turn with the gyro
set yaw angle to 0 start moving with steering 100 (speed 30) wait until yaw > 89 stop moving (4 times, then test 2's three blocks)
Four quarter turns bring the robot back to straight. Compare where it crosses sheet 2's scale with test 2. Try speed 60 too: faster turns overshoot more.
6Stop before the wall
start moving (speed 30) wait until distance < 20 cm stop moving
Read where the wheels stopped on the tape measure, and measure the gap between the robot's front and the box with a ruler. Try 10 cm and speed 70 as well.

What to change when they differ

  • Distance: if the real robot went 78 cm instead of 80, change the set 1 motor rotation to … cm moved block in its program: new value = old value × 78 ÷ 80. Then test 1 again.
  • Drift: a robot that curls one way needs its tires checked (same tires, pushed on all the way) before anything else.
  • Turns: use the gyro (test 5) for turns that matter. For wheel-turn spins, use the real robot's N, not the simulator's.
  • Line, colors, wall: if the real robot coasts further, slow down before the line or the wall. If a color doesn't read, pick another color or use reflected light.
